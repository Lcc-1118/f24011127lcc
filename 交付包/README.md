## 二、核心结论（一页纸）

| 维度 | 现状 | 目标 | 依据 |
|---|---|---|---|
| 退单率 | 21.7% | ≤ 8% | 财务台账 + 试点统计 |
| 单均审核 | 11.5 分钟 | ≤ 6 分钟 | 同上 |
| 制度咨询 | 65 次/天 | ≤ 20 次/天 | 热线/企微统计 |
| 闭环时长 | 9.4 天 | ≤ 5.5 天 | OA 台账 |
| 员工填单 | 28 分钟 | ≤ 12 分钟 | 试点问卷 |

**三个 P0 能力**：制度问答（RAG + 引用 + 弃答）、发票六项硬规则预检、草稿生成 + 强制人工确认。
**边界**：只做草稿，不向 OA/金蝶真实提交；不做 OCR / 税务查验 / 多租户 / 移动 App。

## 四、测试结论

- 场景测试 **55/56 通过**，1 个 P2 缺陷（D-02：发票校验未叠加住宿标准，见 `Test/02-场景过程/边界场景测试.docx`）。
- 评测集 **30/30**；端到端冒烟 **31/31**。
- 离线模式首字 P95 **27ms**、验票 P95 **28ms**；模型故障降级 **2.1s**。
- 部署地址：`http://127.0.0.1:8124`（测试实例）、`http://127.0.0.1:8000`（默认演示）。

## 五、文件说明

- `.docx`：可直接用 Word / WPS 打开；目录页首次打开按 `Ctrl+A` → `F9` 更新页码。
- `.md`：纯文本，便于 git diff 与评审。
- `.html`：自包含流程图，双击浏览器打开，可打印为 PDF。
- `.json/.csv`：访谈原始结构，CSV 带 BOM，Excel 直接打开不乱码。
- `_scripts/`：文档生成脚本（python-docx + Pillow），改动数据后可一键重生成。

## 六、重要声明

1. 客户、人物、金额为方案演练用合成场景，访谈基于角色扮演；正式项目须以客户书面数据为准。
2. 行业分析中的市场规模与渗透率为公开资料量级整理，非审计数据，不构成采购建议。
3. 报价为方案演练报价，最终以合同与 SOW 为准；税率按 6% 增值税估算。
4. 所有验收指标须在试点前由客户项目发起人书面确认分母与排除规则。
